# RITM | ریتم — Persian Running Performance & VDOT Platform

> **هوشمندتر بدو، بهتر پیشرفت کن.**  
> سامانه تخصصی محاسبات علمی عملکرد دویدن بر اساس متدولوژی پیشرفته VDOT دکتر جک دانیلز و جیمی گیلبرت (Jack Daniels' VDOT Methodology).

---

## 🏃 ویژگی‌های کلیدی | Key Features

- **موتور محاسباتی مبتنی بر معادلات فیزیولوژیک دانیلز-گیلبرت**:
  - محاسبه دقیق سرعت متر بر دقیقه
  - تخمین هزینه اکسیژن مصرفی متابولیک ($VO_2$)
  - تابع نمایی کسر پایدار ظرفیت هوازی ($f(t)$)
  - محاسبه معکوس سرعت زون‌های تمرینی از طریق حل معادله درجه دو اکسیژن مصرفی
  - ریشه‌یابی عددی (Numerical Bisection) برای پیش‌بینی زمان مسابقات
- **۵ زون تخصصی تمرین فیزیولوژیک**:
  - **Zone E (Easy Run)**: دویدن آسان و ریکاوری
  - **Zone M (Marathon Pace)**: سرعت اختصاصی ماراتن
  - **Zone T (Threshold / Tempo)**: تمرینات آستانه لاکتات و تمپو
  - **Zone I (VO₂ Max Interval)**: اینتروال‌های هوازی سنگین
  - **Zone R (Repetition Speed)**: تکرارهای سرعتی، اقتصاد دویدن و هماهنگی عصب-عضله
- **طراحی مدرن، بدون هوش مصنوعی زرد (Zero AI-Slop Design)**:
  - پالت رنگی اتلتیک و مینیمال بر اساس قانون ۶۰-۳۰-۱۰
  - زمینه تاریک `#0B0F14` با تاکید سبز فسفری نئونی `#C8FF4D`
  - حالت روشن چشم‌نواز با تایپوگرافی اختصاصی
  - تایپوگرافی فارسی اصیل وزیرمتن (Vazirmatn) و ارقام خوانای ورزشی Inter
- **پشتیبانی دو زبانه و ارقام فارسی/انگلیسی (Bilingual FA/EN & Numerals)**:
  - قابلیت سوییچ کامل بین فارسی (RTL) و انگلیسی (LTR)
  - قابلیت تغییر ارقام به فارسی (۱۲۳) یا انگلیسی (123)
- **پیش‌بینی رکوردهای مسابقه (Race Time Predictor)**:
  - ۱۵۰۰ متر، ۱ مایل، ۳ کیلومتر، ۵ کیلومتر، ۱۰ کیلومتر، نیمه‌ماراتن و ماراتن کامل
  - جستجوگر مسافت هدف دلخواه
- **ماشین‌حساب تکرارها و اسپیلیت‌ها (Track Split Calculator)**:
  - زمان‌بندی دقیق برای فواصل ۲۰۰ تا ۱۲۰۰ متر همراه با هشدارهای ایمنی
- **تاریخچه و مسیر پیشرفت (Performance History Journal)**:
  - ذخیره‌سازی محلی و امن بدون نیاز به ثبت‌نام (۱۰۰٪ آفلاین در LocalStorage)
  - نمودار روند تغییرات VDOT در طول زمان
  - تحلیل مقایسه‌ای پیشرفت نسبت به رکورد قبلی
  - قابلیت پشتیبان‌گیری و بازیابی با فایل JSON
- **آکادمی جامع دویدن (Running Academy)**:
  - ۱۰ مقاله تخصصی تألیفی به زبان فارسی اصیل پیرامون فیزیولوژی، تست‌های ۵K، زون‌های تمرینی و مربی‌گری
- **جعبه‌ابزار دوندگان (Running Tools)**:
  - محاسبه‌گر پیس (Pace Calculator)
  - محاسبه‌گر زمان (Time Calculator)
  - مبدل سرعت (min/km ↔ km/h ↔ min/mile)

npm install
